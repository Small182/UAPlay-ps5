# UAPlay Sources — Stremio / EVO Player (PS5)

Це stream-only Stremio-аддон, який підключає до Stremio/EVO сім пошукових
джерел із **UAPlay-nx**: UAFlix, UASerials, Eneyida, UAFilm, UAKino, Mikai,
AnimeON. Код пошуку й визначення відеопотоку не переписаний: Docker
компілює оригінальний source/catalog.c з фіксованого коміту Switch-репозиторію.

## Що він робить

- Приймає Stremio-ідентифікатори IMDb: tt1234567 для фільмів,
  tt1234567:1:2 для сезону 1 / серії 2.
- Отримує назву з Cinemeta, за потреби українську назву з TMDb.
- Запускає пошук по семи джерелах паралельно в окремих процесах.
- Повертає Stremio JSON зі знайденими HTTP(S)-посиланнями на відео.
- Не потребує Nuvio, ProsperoWeb або WebKit.

Це **серверний аддон**, а не встановлюваний PS5 PKG. Він не працює тільки з
файлами на GitHub: його треба запустити на ПК, NAS, VPS або іншому сервері.
PS5 підключається до його URL через EVO Player / Stremio. Компільований C
пошуковий модуль запускається на сервері Linux, **не на PS5**.

## Запуск із Docker

У корені репозиторію:

    docker build -t uaplay-stremio ./stremio-addon
    docker run -d --restart unless-stopped --name uaplay-stremio -p 7000:7000 uaplay-stremio

Для локальної перевірки:

    curl http://localhost:7000/manifest.json
    curl http://localhost:7000/health

Перевірка Stremio API для фільму:

    curl http://localhost:7000/stream/movie/tt1254207.json

Порожній список streams означає, що в обраних джерелах немає підтвердженого
прямого посилання або сталася помилка пошуку. Це не гарантія відтворення.
Окремі відеосервіси можуть вимагати cookies, referer або блокувати запити.

## Підключення до PS5

1. PS5 і сервер з аддоном повинні бачити один одного в мережі.
2. Визначте локальний IP сервера, наприклад 192.168.3.169.
3. У нативному EVO Player відкрийте Stremio Addons / Add addon.
4. Додайте адресу **http://192.168.3.169:7000/manifest.json**,
   замінивши IP на адресу вашого сервера.
5. Для каталогів використовуйте Cinemeta, що вже підтримується EVO;
   UAPlay додає саме потоки до знайдених фільмів і серій.

В інших реалізаціях Stremio для віддаленої інсталяції може бути потрібен
HTTPS: налаштуйте reverse proxy із сертифікатом.

Якщо налаштовуєте EVO вручну, конфігурація має містити поле addons зі
списком manifest URL. Не перезаписуйте наявні аддони.

## Покращення пошуку українською

Опційно вкажіть ключ TMDb, щоб шукати українську локалізовану назву:

    docker run -d --restart unless-stopped --name uaplay-stremio \
      -p 7000:7000 -e TMDB_API_KEY=YOUR_TMDB_KEY uaplay-stremio

Це публічний API ключ TMDb, а не обліковий запис Stremio.

## Розробка й перевірка

У Docker збирається файл bin/uaplay_bridge (Linux / amd64 залежно від архітектури);
без Docker його можна скомпілювати на Linux, маючи gcc, pkg-config і libcurl
та каталоги upstream/source з UAPlay-nx. Потім:

    BRIDGE_PATH=./bin/uaplay_bridge node server.js

Тести, що не звертаються до зовнішніх сайтів:

    node --test tests/*.test.js

## Обмеження станом на перший варіант

- Наявність результатів у семи провайдерів залежить від зовнішніх сайтів,
  географії, антибот-захисту та чинних URL. Автоматичні тести не доводять,
  що конкретний фільм відтворюється на PS5.
- Не перевірено на фізичній PS5 із прошивкою 13.60.
- Потрібен постійно запущений сервер та мережеве з'єднання.
- Працює з легально доступними користувачу відеопотоками; відповідальність
  за право перегляду вмісту несе користувач.
- Дані каталогів показує Cinemeta, а UAPlay повертає лише streams.
- Щоб оновити парсери, змініть UPSTREAM_COMMIT у Dockerfile і ref у workflow,
  після чого повторіть перевірки.
